# Architecture

## Layers

```
src/
  app/                 Next.js routes (App Router). No pages yet
    layout.tsx         Root: font, global metadata, Organization and WebSite JSON-LD, SiteBanner
    sitemap.ts         Generated from the route registry
    robots.ts          Generated by lib/seo/robots.ts
    llms.txt/route.ts  Generated by lib/seo/llms.ts (static)
    opengraph-image.tsx  Share image: logo, tagline, brand red (fonts from assets/fonts)
    icon.png, apple-icon.png, manifest.ts
  components/          Presentational Server Components (JsonLd, SiteBanner)
  lib/
    site.ts            Site identity (name "Car's Secrets", brand colours) and URL resolution
    og.ts              Fonts and logo loader for generated images
    routes.ts          Registry of every public page
    deal.ts            Deal arithmetic: acquisition cost, profit, margin, max bid
    seo/               Metadata, JSON-LD, robots, sitemap and llms.txt builders
public/
  brand/               logo-light.png, logo-dark.png (transparent, 879×120, ~7 KB),
                       icon-192.png, icon-512.png (manifest)
assets/
  fonts/               Libre Franklin 400 and 800 as woff, plus OFL licence
```

Dependencies point downward: `app` → `components` → `lib`. The
modules in `lib` are pure functions with no React, so tests can cover them
directly.

## Layout

The site is full width. There is no centered page container: sections span
the viewport with side padding, and only running text is capped at a readable
line length. The top banner shows the brand logo. A `<picture>` element serves
`logo-dark.png` (with a white "Secrets") under `prefers-color-scheme: dark`, so
each visitor downloads one logo.

The logo files were generated from the original artwork: cropped, white
background removed, resized to 3× the 36px display height, and quantized to 16
colours. At about 7 KB each, they are smaller than the AVIF or WebP versions the
image optimizer produced, so they are served directly.

The icons (`src/app/icon.png` 192×192, `src/app/apple-icon.png` 180×180, and
the 192 and 512 manifest icons) are the red "C" cut from the wordmark, on
white. `brand-assets.test.ts` checks every file's dimensions against what the
code declares.

## Share image

`src/app/opengraph-image.tsx` renders the Open Graph and Twitter image with
`next/og`. That renderer can't use `next/font` or CSS, and reads only static
woff, ttf or otf fonts (not woff2 or variable fonts). So `src/lib/og.ts` reads
the Libre Franklin 400 and 800 woff files from `assets/fonts/` and the logo from
`public/brand/`. Without those fonts it falls back to a single built-in weight
and ignores `fontWeight`.

## Route registry

`src/lib/routes.ts` lists every indexable page with its title, description,
sitemap priority, and whether it appears in `llms.txt`.
It is empty until the first page is built. Pages read their metadata from it
through `metadataForRoute(path)`. `routes.test.ts` fails if a static `page.tsx`
under `src/app` is missing from the registry. The builders take an optional
route list, and tests pass them `src/lib/seo/fixtures.ts`.

## SEO module

- **Site URL.** `resolveSiteUrl` uses `NEXT_PUBLIC_SITE_URL`, falling back to
  `http://localhost:3000`. Only a `NEXT_PUBLIC_` variable is used, because
  Next.js inlines those into client bundles too, so server and browser always
  agree on the value. Every absolute URL goes through `absoluteUrl()`.
- **Metadata.** `buildMetadata` sets the title, description, canonical URL,
  Open Graph, Twitter card and robots directives. When a page sets
  `openGraph`, it replaces the file-based share image it would have inherited,
  so the image is attached explicitly.
- **Structured data.** The root layout emits Organization and WebSite data on
  every page, with `alternateName` listing the other spellings of the brand. Builders for WebApplication, FAQPage, BreadcrumbList and Article
  are ready for pages to use. `serializeJsonLd` escapes `<`.
- **AI crawlers.** `robots.txt` is a single `User-Agent: *` / `Allow: /` rule,
  which admits every crawler, AI search and assistant bots (GPTBot, ClaudeBot,
  PerplexityBot, Google-Extended and others) included. `/llms.txt` summarizes
  the site and links its key pages.
- **Rendering.** Pages should be prerendered to static HTML, so crawlers that
  don't run JavaScript still see the full content.
