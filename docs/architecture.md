# Architecture

## Layers

```
src/
  app/                 Next.js routes (App Router). No pages yet
    layout.tsx         Root: font, global metadata, Organization and WebSite JSON-LD
    sitemap.ts         Generated from the route registry
    robots.ts          Generated by lib/seo/robots.ts
    llms.txt/route.ts  Generated by lib/seo/llms.ts (static)
    opengraph-image.tsx, logo.png/route.tsx, icon.svg, manifest.ts
  components/          Presentational Server Components (JsonLd)
  lib/
    site.ts            Site identity and URL resolution
    routes.ts          Registry of every public page
    deal.ts            Deal arithmetic: acquisition cost, profit, margin, max bid
    seo/               Metadata, JSON-LD, robots, sitemap and llms.txt builders
```

Dependencies point downward: `app` → `components` → `lib`. The
modules in `lib` are pure functions with no React, so tests can cover them
directly.

## Route registry

`src/lib/routes.ts` lists every indexable page with its title, description,
sitemap priority, and whether it appears in the navigation or in `llms.txt`.
It is empty until the first page is built. Pages read their metadata from it
through `metadataForRoute(path)`. `routes.test.ts` fails if a static `page.tsx`
under `src/app` is missing from the registry. The builders take an optional
route list, and tests pass them `src/lib/seo/fixtures.ts`.

## SEO module

- **Site URL.** `resolveSiteUrl` uses `NEXT_PUBLIC_SITE_URL`, then
  `RENDER_EXTERNAL_URL`, then `http://localhost:3000`. Every absolute URL goes
  through `absoluteUrl()`.
- **Metadata.** `buildMetadata` sets the title, description, canonical URL,
  Open Graph, Twitter card and robots directives. When a page sets
  `openGraph`, it replaces the file-based share image it would have inherited,
  so the image is attached explicitly.
- **Structured data.** The root layout emits Organization and WebSite data on
  every page. Builders for WebApplication, FAQPage, BreadcrumbList and Article
  are ready for pages to use. `serializeJsonLd` escapes `<`.
- **AI crawlers.** `robots.txt` names GPTBot, ClaudeBot, PerplexityBot,
  Google-Extended and the other AI crawlers and allows them. `/llms.txt`
  summarizes the site and links its key pages.
- **Rendering.** Pages should be prerendered to static HTML, so crawlers that
  don't run JavaScript still see the full content.
